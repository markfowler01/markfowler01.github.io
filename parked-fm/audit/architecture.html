PARKED FM Uploader: architecture

Internal tool, single user (the PARKED FM channel owner). Runs once a day.

1 · SCHEDULE

GitHub Actions

Daily scheduled job in the owner's GitHub repository.

2 · CREATE

Build the video

  • Original lo-fi music (own code)
  • Car artwork (AI image)
  • Full video, thumbnail, 30 s trailer
3 · AUTHORIZE

OAuth 2.0 token

Refresh token from an encrypted GitHub secret is exchanged for a short-lived access token. Scope: youtube.upload.

4 · YOUTUBE API

YouTube Data API v3

  • videos.insert full video
  • thumbnails.set
  • videos.insert Short, linked to the full video
5 · RESULT

PARKED FM channel

New video and Short on the owner's own channel, labeled altered/synthetic, not made for kids.

One-time setup (owner only)

The owner runs a small script once, signs in on Google's consent screen, chooses the PARKED FM channel, and saves the resulting refresh token as a GitHub secret. No other users ever sign in.

Data handling

No YouTube data is read, stored, or shared. The only value kept is the new video's ID, used once to link the Short. Access can be revoked at any time in Google Account security settings.
